# Sunshine Construction Project Charter

## 1. Project Overview

**Project Name:** Sunshine Residential Construction Project

**Company:** Sunshine Construction

**Industry:** Construction & Real Estate Development

**Location:** Addis Ababa, Ethiopia

**Project Role:** Assistant Project Manager & Data Analyst

---

## 2. Business Case

Sunshine Construction requires effective project monitoring to ensure construction activities are completed on time, within budget, and according to quality standards.

This project applies project management techniques and data analytics to track project performance, identify risks, analyze costs, and provide actionable insights for management decision-making.

---

## 3. Project Objectives

The objectives of this project are:

- Monitor construction project progress
- Track budget and cost performance
- Analyze resource utilization
- Identify potential project risks
- Improve decision-making using data analytics
- Develop dashboards for executive reporting

---

## 4. Project Scope

### Included:

- Project planning documentation
- Schedule tracking
- Budget analysis
- Resource monitoring
- Risk management
- Data analysis
- Power BI dashboard development

### Excluded:

- Actual construction execution
- Engineering design activities
- Physical site supervision

---

## 5. Key Stakeholders

| Stakeholder | Role |
|---|---|
| Project Sponsor | Provides project approval and funding |
| Project Manager | Oversees project delivery |
| Assistant Project Manager | Supports planning, tracking, reporting, and analysis |
| Construction Team | Executes project activities |
| Suppliers | Provide construction materials |
| Management Team | Reviews project performance |

---

## 6. Success Criteria

The project will be successful if:

- Project performance can be clearly measured
- Budget and schedule issues are identified early
- Management receives accurate reports
- Data-driven decisions improve project outcomes
